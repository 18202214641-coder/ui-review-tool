# UI 验收工具

一个面向设计师和前端的静态网站，用来上传设计稿截图和开发截图，自动筛出明显的 UI 差异并高亮定位。

## 功能

- 上传设计稿截图和开发截图
- 自动检测明显的颜色、字号、圆角、间距、对齐问题
- 在右侧生成问题列表
- 点击问题后在画布中高亮区域
- 在左侧预览设计稿与开发稿的局部问题区域
- 支持问题状态筛选：全部、待确认、已确认、已忽略
- 支持问题详情展开、备注记录与状态操作

## 本地运行

在项目目录执行：

```bash
python3 -m http.server 8125 --bind 127.0.0.1
```

然后打开：

```text
http://localhost:8125
```

## 项目结构

- `index.html`: 页面结构
- `styles.css`: 页面样式
- `src/app.js`: 上传、状态管理、问题列表交互、局部预览
- `src/detection.js`: 启发式视觉检测逻辑
- `start.command`: 本地一键启动脚本

## 部署为网站

这个项目是纯静态站点，不依赖后端，也不需要构建步骤，可以直接部署到：

- Vercel
- Netlify
- GitHub Pages
- 公司内部静态资源服务器

部署时只需要保留这些文件：

- `index.html`
- `styles.css`
- `src/app.js`
- `src/detection.js`

## 已知限制

- 适合同尺寸、同视口的静态截图
- 不做 OCR 语义比对
- 不适合替代像素级验收
- 目前备注和问题状态仅保存在浏览器当前页面内，刷新后不会持久化
